# マビモバ 日課・週課リスト

マビノギモバイルのデイリー / ウィークリー作業をブラウザ上でチェックするためのリストです。
サーバー不要の静的ページで、データはすべて各自のブラウザの **localStorage** に保存されます。

## 使い方

- `index.html` をブラウザで開くだけで動きます（ダブルクリックでの `file://` 表示でも可）。
- Web で共有する場合は、このフォルダをそのまま静的ホスティング（GitHub Pages、社内の Web サーバー等）に置いてください。ビルド不要です。

## 機能

| 機能 | 説明 |
|---|---|
| デイリー / ウィークリー表示 | 2 列で表示。項目をクリックで完了、回数つき項目は「−」「＋」で回数を進める |
| 自動リセット | 既定で **デイリーは毎日 6:00、ウィークリーは毎週月曜 6:00**（日本版公式準拠）。期限を過ぎると達成度が自動で未完了に戻る |
| 表示項目のカスタマイズ | 各列の見出し右にある「表示項目」ボタンから表示 / 非表示の切り替え、並べ替え、名前・回数・メモの編集、独自項目の追加。並び順がそのまま表示順になり、カテゴリが変わる位置に見出しが入る |
| 曜日限定項目 | 曜日を指定した項目はその曜日のデイリー列にだけ出る（例: 輝く洞窟 = 月・木・日） |
| 物々交換 | 1 交換 = 1 項目で、ティルコネイル / ダンバートン / ドゥガルドアイル / コレンの 29 NPC・82 件を収録。カードは「NPC 名（町）／渡す素材×数 → 入手素材×数／素材の入手方法」の 3 行。毎日回す定番 7 件だけ初期表示、残りは「表示項目」から ON にする。回数・素材名は攻略記事ベースなのでゲーム内表示と違えば「編集」で直す |
| 完了を隠す | フッターのチェックで完了済み項目を折りたたむ |
| エクスポート / インポート | 設定・表示項目・独自項目・進捗を JSON で書き出し / 読み込み。別ブラウザや別端末へ移すときに使う |
| リセット時刻の変更 | 「設定」からデイリー時刻・ウィークリー曜日 / 時刻を変更可能 |
| 配色 | [Catppuccin](https://catppuccin.com) の 4 フレーバー（Latte / Frappé / Macchiato / Mocha）から選択。既定は OS 設定に追従（ライト = Latte、ダーク = Mocha）。デイリー = Peach、ウィークリー = Mauve、カテゴリごとに固定色（戦闘 = Red、生活 = Green など） |

## リセットの判定方法

- 時刻はブラウザ（端末）のローカル時刻で判定します。
- 「リセット時刻を 0 時とみなした日付」を期間キーとして進捗と一緒に保存し、ページ表示時・タブ復帰時・30 秒ごとに現在の期間キーと比較して、違っていればその種別の進捗を空にします。
  - 例: 月曜 5:59 はまだ「日曜のデイリー」「先週のウィークリー」、6:00 になると両方が切り替わります。
- ブラウザを閉じている間に期限を跨いでも、次に開いたときにリセットされます。

## ファイル構成

```
index.html      画面
css/style.css   スタイル（ライト / ダーク対応）
js/tasks.js     既定のタスク一覧（ここを編集すると全員の既定項目が変わる）
js/app.js       アプリ本体（依存ライブラリなし）
```

### 既定タスクの編集（`js/tasks.js`）

```js
{ id: "w_barrier", type: "weekly", category: "戦闘", name: "不吉な召喚の結界",
  count: 7, note: "戦利品は週 7 回まで", default: true },
```

- `id` は保存データとの紐付けに使うので、一度公開したら変更しないでください。
- `name` が 1 行目、`sub` が 2 行目（「→」の前後で折り返し）、`note` が 3 行目、`place` は名前の横の小さなラベル。`type` は `daily` / `weekly`、`count` は 1 周期あたりの回数（省略時 1）、`days` は表示曜日の配列（0=日 〜 6=土、省略時は毎日）、`default` が `true` のものは初期状態で表示されます。
- 新しい `id` を追加すると、既存ユーザーの画面でも同種別の末尾に追加されます。

## 保存データ

localStorage のキー `mabimoba_worklist_v1` に 1 つの JSON として保存します。

```json
{
  "settings":    { "dailyResetHour": 6, "weeklyResetDay": 1, "weeklyResetHour": 6, "hideCompleted": false, "theme": "auto" },
  "visible":     { "<タスクid>": true },
  "order":       ["<タスクid>", "..."],
  "overrides":   { "<既定タスクid>": { "name": "...", "count": 3 } },
  "customTasks": [ { "id": "c_...", "type": "weekly", "name": "...", "category": "...", "count": 1, "note": "", "days": [] } ],
  "progress":    { "daily": { "period": "2026-10-15", "done": { "<タスクid>": 1 } },
                   "weekly": { "period": "2026-10-12", "done": { "<タスクid>": 3 } } }
}
```

## 配色のカスタマイズ

色はすべて `css/style.css` 先頭の CSS 変数で定義しています。

- `--ctp-*`: Catppuccin 公式 [palette.json](https://github.com/catppuccin/palette) の値（フレーバーごと）
- `--bg` / `--panel` / `--card` / `--border` など: 背景・パネル・カードの役割色（ライト用とダーク用の 2 セット）
- `--daily` / `--weekly` / `--primary` / `--cat-*`: アクセントとカテゴリ色。別の Catppuccin 色にしたいときはここだけ書き換える

## 既定タスクの出典

- マビノギモバイル公式「日次/週次コンテンツのリセットタイミング」
- GameWith / Gamerch / ゲーム先取り などの攻略記事（2026 年 10 月時点）

ゲーム側のアップデートで内容や回数が変わることがあるため、実際の回数はゲーム内表示を優先し、必要に応じて「表示項目」→「編集」で調整してください。

## GitHub Pages での公開

1. GitHub のリポジトリで **Settings → Pages** を開き、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存する。
2. 数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` で表示される。相対パスだけで組んであるので、サブパス配下でもそのまま動く。
3. 独自ドメインを使う場合は、同じ画面の **Custom domain** に入力して保存する。GitHub が `CNAME` ファイルを `main` に自動でコミットするので、以後そのファイルは消さないこと。DNS 側では `CNAME`（サブドメイン）または `A` レコード（apex ドメイン）を GitHub Pages に向ける。
4. `.nojekyll` は Jekyll による変換を止めるための空ファイル。削除しない。

localStorage はドメイン単位で分かれるため、`github.io` の URL と独自ドメインの間でデータは共有されない。ドメインを切り替えるときは設定画面のエクスポート／インポートで移す。
