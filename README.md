# マビモバ 日課・週課リスト

マビノギモバイル（日本版）のデイリー / ウィークリーをブラウザでチェックするためのリストです。ログイン不要、データは自分のブラウザの中にだけ保存されます。

**公開 URL:** https://mabimobaworklist.tyuukiti.com/

## できること

- **デイリー / ウィークリーの 2 列表示**。カードをクリックで完了、回数つきの項目は「−」「＋」で進めます。
- **自動リセット**。デイリーは毎日 6:00、ウィークリーは毎週月曜 6:00（日本版公式準拠）に達成状況が未完了へ戻ります。リセット時刻は設定で変更できます。
- **表示項目のカスタマイズ**。各列の「表示項目」から、表示する項目の選択、並べ替え、名前・回数・メモの編集、独自項目の追加ができます。カード右上の × でも項目を外せます。
- **曜日で変わる項目**。曜日ダンジョンは曜日に合わせてカードの内容（輝く洞窟 / 眩い邸宅 / 煌めく遺跡 / 日曜は選択）が切り替わります。
- **物々交換**。ティルコネイル / トゥガルドアイル / ダンバートン / コレンの 29 NPC・82 件を 1 交換 1 項目で収録。NPC 名、「渡す素材 → 入手素材」、素材の入手方法の 3 行で表示します。毎日回す定番だけ初期表示で、残りは「表示項目」から選べます。
- **エクスポート / インポート**。設定と進捗を JSON で書き出し・読み込みでき、別のブラウザや端末へ移せます。
- **配色**。[Catppuccin](https://catppuccin.com) の Latte / Frappé / Macchiato / Mocha から選べます。既定は OS のライト / ダーク設定に追従します。

## データの保存について

- 保存先はブラウザの localStorage です。サーバーには何も送信しません。
- ブラウザやドメインが変わるとデータは引き継がれません。移すときは設定画面のエクスポート / インポートを使ってください。
- ブラウザのサイトデータを削除すると設定と進捗も消えます。

## 注意

- 項目の回数や素材名はゲームのアップデートで変わることがあります。ゲームのアップデートで変わることがあるので、実際の表示と違う場合はゲーム内を優先し、「表示項目」→「編集」で直してください。
- リセットの判定は端末のローカル時刻で行います。
